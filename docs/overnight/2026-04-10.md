### Django Security Detail (last 30 days)

**April 7, 2026 releases (Django 6.0.4, 5.2.13, 4.2.30):**
- **CVE-2026-3902**: ASGI header name normalization allows security-sensitive header spoofing via underscore/hyphen confusion
- **CVE-2026-33034**: ASGI requests with missing/understated Content-Length bypass DATA_UPLOAD_MAX_MEMORY_SIZE, enabling unbounded memory consumption
- CVE-2026-4277, CVE-2026-4292, CVE-2026-33033: Additional fixes

**March 3, 2026 releases (Django 6.0.3, 5.2.12, 4.2.29):**
- **CVE-2026-25673**: URLField.to_python() DoS via slow NFKC normalization on Windows
- **CVE-2026-25674**: Race condition in file-system storage/cache backends causing incorrect permissions

**Django 5.1.x is no longer receiving security updates.** The project must upgrade to at least Django 5.2.13 (LTS) or Django 6.0.4.
