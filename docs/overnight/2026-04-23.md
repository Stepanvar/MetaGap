| `app/locale/ru/LC_MESSAGES/django.po` | 325 | ? | **`375 translated messages.`** ← fully translated despite yesterday's 53-raw-empty-line count. The raw grep was counting multi-line-string continuations, not untranslated entries. |
| `MetaGap/locale/en/LC_MESSAGES/django.po` | 2 | 2 | `0 translated messages, 2 untranslated messages.` |
| `MetaGap/locale/ru/LC_MESSAGES/django.po` | 2 | ? | (OK, previously verified full) |

**Impact of `app/locale/en` malformation:** the in-tree custom compiler (`app/utils/locale_compiler.py`) silently skips entries that transition from `_ID_SECTION` to `#:` without ever entering `_STR_SECTION` — so no exception. The installed `django.mo` is **231 bytes** (header only) vs `.po` file 32.5 KB. Django falls back to `msgid` for English so users see correct English anyway; no crash. But: `msgfmt` would fail in any pipeline that uses it (e.g. `django-admin compilemessages`), and `test_locale_compiler.py` is pytest-only so there's no CI signal. Real risk is a future translator or CI hook assuming the file is well-formed.

**Recommended fix:** re-generate via `django-admin makemessages -l en` to reinsert `msgstr ""` on every entry, or hand-patch via a small sed/awk script. Then re-run `msgfmt --statistics` to verify.

## Research Findings

### Django Updates & Deprecations

- **Django 5.2.13** (2026-04-07) is the minimum safe 5.x pin. Five minor CVE cycles since 5.2.0. LTS through 2028-04.
- New in 5.2.13 beyond previously tracked CVEs: **CVE-2026-3902** — ASGI normalizes header hyphens→underscores WSGI-style, so a header named with underscores could spoof the hyphen-form reverse-proxy-stripped one. Django now ignores headers containing underscores on ASGI. Affects only ASGI deployments; current MetaGap runs WSGI via gunicorn (not ASGI), so not live-risk — but gate before switching to Daphne/Uvicorn.
- Upgrade-path deprecations to audit (restated from 2026-04-22):
  - `all=` → `find_all=` on `staticfiles.finders.find()` — whitenoise downstream.
  - `request.user`/`request.auser()` fallback when `user is None` in `auth.login`/`alogin` — affects django-allauth.
  - `ArrayAgg`/`JSONBAgg`/`StringAgg` `ordering=` → `order_by=` — not used here (verified).
- Django 6.0 pre-gating: `Prefetch.get_current_queryset()`, `get_prefetch_queryset()`, `get_joining_columns()`, positional args to `Model.save()/asave()`. None obviously used in `app/`.

### VCF/Genomics Horizon

- **VCF 4.4** (`VCFv4.4.pdf` in hts-specs) is current published. Project fixtures still `VCFv4.2` — safe.
- **VCF 4.5 draft** still active (`VCFv4.5.draft.tex`), notable direction: modified-base info in genotype records. Discussion on issue #767 pushes back on special-casing and suggests `ALT`-column representation instead. Not actionable for the import pipeline until pysam/vcfpy expose consumer APIs.
- pysam 0.23.3 currently wraps htslib 1.23.1; early-0.23 patch releases bundled htslib 1.21 — **pin exact patch version when bumping** to avoid silent htslib downgrade.
