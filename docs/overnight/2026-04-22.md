## Research Findings

### Django Updates & Deprecations

- **Django 5.2 LTS (released 2025-04-02, support through Apr 2028)** remains the correct target. Five clean minor CVE releases since 5.2.0 — `5.2.13` is the current stable.
- Useful-here features in 5.2:
  - Shell auto-imports (13 metadata models at current schema size → meaningful QoL).
  - `Model._is_pk_set()` — tighten pre-delete guard in `SampleGroup.delete()` (currently walks `getattr(self, field_name, None)`).
  - `CompositePrimaryKey` — future option if `AlleleFrequency`'s 5-field unique constraint ever needs PK-level semantics.
  - `HttpRequest.accepted_types` preference-sorted — useful if export endpoints grow content negotiation (JSON/TSV/VCF).
- Deprecations to audit on the upgrade path:
  - `all=` → `find_all=` on `staticfiles.finders.find()` (whitenoise downstream).
  - `request.user`/`request.auser()` fallback when `user is None` in `auth.login`/`alogin` — affects django-allauth upgrade path.
  - `ArrayAgg`/`JSONBAgg`/`StringAgg` `ordering=` → `order_by=` — not currently used (verified: no `ArrayAgg` in codebase).
  - MySQL `utf8mb4` default — irrelevant (sqlite dev, likely pg prod).
- Django 5.2 min PostgreSQL is 14; min Python 3.10 (Py3.11 used here — fine).
- Django 6.0 removals to gate before going past 5.2: `Prefetch.get_current_queryset()`, `get_prefetch_queryset()`, `get_joining_columns()`, positional args to `Model.save()/asave()`, `BaseDatabaseOperations.field_cast_sql()`. None obviously used.

### VCF/Genomics Horizon

- **VCF 4.4 (BCFv2.2)** is the current published spec; project fixtures still `VCFv4.2` — remains universal and safe.
- **VCF 4.5 draft** is active in `samtools/hts-specs` (`VCFv4.5.draft.tex`); notable draft directions:
  - Modified-base information in genotype records (methylation → variant annotation).
  - Tumor/normal multi-genome clonal-derivation support.
  - Library-API recommendations for value access (affects pysam/vcfpy, not consumers).
  - Not actionable yet — tag for backlog when pysam 0.23.x/0.24.x ships consumer APIs.
- pysam 0.23.3 quality-of-life improvements: GT-reset bug fixed in `VariantHeader.new_record()` (not currently called in codebase, but guard for future import-reverse flow).
- Long-term scaling note for `AlleleFrequency`: community interest in sparse/population-scale variant representations (Oxford Academic 2025 paper cited in 2026-04-20 report); relevant once the table grows to multi-million rows.
