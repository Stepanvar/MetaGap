## Research Findings

### Django Updates & Deprecations

Three security drops since the 5.1.1 pin worth highlighting (full chain at `https://docs.djangoproject.com/en/5.2/releases/security/`):

- **2026-04-07 (5.2.13 / 6.0.4 / 4.2.30)** — ASGIRequest now strips underscores in headers (Daphne parity); `GenericInlineModelAdmin` add-permission validated on POST; `ModelAdmin.list_editable` no longer permits creation via forged POST. The list-editable issue is exploitable in any admin where a `list_editable` field is exposed alongside auto-creation.
- **2026-03-03 (5.2.12 / 6.0.3 / 4.2.29)** — `forms.URLField.to_python()` DoS on Windows (NFKC normalization in `urllib.parse.urlsplit`).
- **2026-02-03 (5.2.11 / 6.0.2 / 4.2.28)** — GIS SQLi.

The codebase uses `URLField`, `admin.ModelAdmin` (no current `list_editable` usage seen — `grep` clean), and ASGI is enabled via gunicorn. The list-editable patch is preventative for now; the ASGI underscore-header and `URLField` patches are directly relevant.

5.2 is a drop-in upgrade for this codebase: no use of `staticfiles.finders.find(all=…)` or `postgres.aggregates ordering=` (re-checked today). Recommend bumping straight to 5.2.13 LTS and verifying with `python manage.py test`.

### VCF/Genomics Horizon

- **VCF 4.5 is now the canonical hts-specs release** (PDF dated 9 Oct 2024 lives at `samtools.github.io/hts-specs/VCFv4.5.pdf`; master tex is `VCFv4.5.draft.tex`). Yesterday's report still described 4.4 as the working draft — that is now stale. Differences vs 4.4 are documented in the spec's "Changes between 4.5 and 4.4" section. Practical implications for this importer:
  - 4.5 introduces additional structural-variant attributes and refines pedigree/sample header records. The current importer ingests unknown header sections into `SampleGroup.additional_metadata` (lossy but safe), so 4.5 files will not break import — they will silently lose the new structured attributes.
  - htslib 1.21 (pysam 0.23.3) has partial 4.5 awareness; htslib 1.22+ (when released) is expected to be fully 4.5-aware. Worth tracking before promising VCF 4.5 fidelity.
- **2026 ecosystem otherwise unchanged** vs yesterday: cyvcf2 (~7× pysam read throughput), vembrane (Python-expression filter/transform), pygenomics (no-deps pure-Python). No dominant new entrant warranting architectural change.
