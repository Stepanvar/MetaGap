{% blocktrans with site_name=SITE_NAME %}{{ site_name }} is a web platform for unifying, aggregating, and visualising variant data from VCF/gVCF files.{% endblocktrans %}

{% trans "MetaGaP is an open platform for exploring cohort-level variant frequencies." %}

{% trans "Platform capabilities" %}

  • {% trans "Import and basic validation of VCF/gVCF files with support for GRCh37 and GRCh38 assemblies." %}
  • {% blocktrans %}Merge multiple VCFs into a cohort-level file and recalculate AC/AN/AF tags using bcftools +fill-tags.{% endblocktrans %}
  • {% blocktrans %}Apply filters (QUAL, PASS, and more) and remove genotype columns during export to support de-identification.{% endblocktrans %}
  • {% trans "Leverage tables and filters (django-tables2, django-filter) for streamlined browsing and navigation." %}

{% trans "How it works" %}

  1. {% blocktrans %}Each input VCF is normalised with bgzip + tabix and validated for readability and a compliant header.{% endblocktrans %}
  2. {% blocktrans %}Cohort merging runs via bcftools merge -m all followed by recalculation of summary tags (AC/AN/AF).{% endblocktrans %}
  3. {% blocktrans %}Configured filters are applied; genotype data can be stripped with bcftools view -G. The final VCF and index are then produced.{% endblocktrans %}

{% trans "Reliability and quality control" %}

  • {% blocktrans %}Format validation and error logging for external tools (bcftools, bgzip, tabix).{% endblocktrans %}
  • {% trans "Automated tests cover key merge and import scenarios, and community regression suites are welcome." %}

{% trans "Limitations and disclaimer" %}

{% trans "The platform is intended for research use only and is not a medical device. Do not upload personal or clinical genomic data; use synthetic examples or de-identified metadata." %}

{% trans "Technology stack" %}

{% trans "Django 5, Python 3.12/3.13, bcftools/htslib, pysam, Bootstrap 5, django-bootstrap5, django-tables2, django-filter, backed by SQLite or PostgreSQL." %}
