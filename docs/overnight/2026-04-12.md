## Research Findings

### Django Updates & Deprecations

**Django 5.2 LTS** (released April 2025) is the recommended upgrade target:
- New `LoginRequiredMiddleware` — could replace per-view `LoginRequiredMixin` pattern
- Composite primary keys support
- Automatic `manage.py shell` model imports
- `response.text` property for decoded response body
- `AlterConstraint` migration op — no-op constraint alteration without drop/recreate
- Python 3.10+ required, PostgreSQL 14+ required

**Django 5.1 Deprecations that bite in 5.2**:
- `DEFAULT_FILE_STORAGE` → `STORAGES["default"]` — check `settings.py`
- Watch for `RemovedInDjango52Warning` in test output

**Django 6.0** (released December 2025): drops Python 3.10. Target 5.2 LTS first, then evaluate 6.0.

### VCF/Genomics Horizon

**VCF 4.5 released in 2025** by GA4GH. Key additions: local allele encoding, per-sample reference block definitions for large-cohort scale. VCF 4.4 remains common baseline. MetaGap pipeline likely sees 4.3/4.4 headers; 4.5 adoption will lag.

**pysam + htslib remain dominant**. Main alternative is **cyvcf2** (Cython wrapper, 6-168x faster for variant iteration). Not needed for metadata extraction but worth watching for bulk import performance.

**New tools**:
- **vcfexpress** (Rust + Lua, March 2025) — fast VCF filtering, CLI-only
- **polars-bio** (Python, Dec 2025) — genomic interval ops on Polars DataFrames, includes VCF reader

**Metadata conventions**: No new standard beyond VCF 4.3+ `##META` lines for phenotype metadata. Convention: all custom INFO/FORMAT tags must be declared in header — tools increasingly enforce this. MetaGap's `additional_metadata` fallback handles unrecognized headers correctly.

**Action items**: Parser should not hard-reject `fileformat=VCFv4.5`. `##META` phenotype blocks (4.3+) not yet mapped in `metadata_fields.yaml` — potential future enrichment.
